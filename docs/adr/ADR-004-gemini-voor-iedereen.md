# ADR-004: Gemini-accounts van de trainer voor iedereen

| | |
|---|---|
| **Status** | Vervangen door ADR-005 |
| **Datum** | 2026-11-04 |
| **Besloten door** | Witek ten Hove (trainer en ontwerper) |
| **Document** | [LRD AISO26009 Lesdagen](../../LRD-AISO26009-lesdagen.html) |

## Context

Deelnemers moeten met een frontiermodel werken om te ervaren wat AI nu kan. Gratis of door de organisatie afgeschermde tools laten dat slecht zien, en sommige organisaties staan geen publieke tools toe.

## Besluit

Iedereen werkt in de werkplaatsen met een Gemini-account dat de trainer aanmaakt.

## Overwogen alternatieven

- **Elke tool die de organisatie toestaat.** Vaak gratis of afgeschermd.

## Gevolgen

- Vervangen: direct na dit besluit gaf de trainer aan dat eigen accounts de voorkeur hebben en de Gemini-accounts reserve zijn (ADR-005).

## Raakt

NFR-01 t/m NFR-03 (inmiddels herschreven).
